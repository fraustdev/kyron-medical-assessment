## Cross-panel consensus
1. Failures run in both directions: over-caution (re-verification, lectures, deferral, refusal) and carelessness (wrong drug/store, a false "done").
2. The task continues alongside escalation unless the tier is 911.
3. "No" must come with a concrete next step (renewal request, pharmacist, which store).
4. End every call with a read-back or recap.
